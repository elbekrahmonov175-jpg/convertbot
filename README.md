# MTS → MP4 Telegram Bot

Конвертирует `.mts` и `.m2ts` файлы в MP4 прямо в Telegram.

## Возможности

- Конвертация через ffmpeg (`-c:v copy` — без перекодирования, максимальная скорость)
- Очередь до 2 параллельных задач
- Прогресс и статус в реальном времени
- Ограничение очереди на пользователя (3 задачи)
- Команда `/cancel` для отмены
- Опциональный whitelist пользователей

## Переменные окружения (Railway)

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен от @BotFather |
| `ALLOWED_USERS` | ❌ | ID пользователей через запятую. Если пусто — доступ для всех |
| `WORK_DIR` | ❌ | Папка для временных файлов (по умолчанию `/tmp/convertbot`) |

## Деплой на Railway

1. Залить код на GitHub
2. В Railway: **New Project → Deploy from GitHub**
3. Выбрать репозиторий
4. В **Variables** добавить `BOT_TOKEN`
5. Railway сам соберёт Docker образ

## Ограничения

- Максимальный размер файла: **2 GB** (ограничение Telegram Bot API)
- Временные файлы хранятся в `/tmp/convertbot` и удаляются после отправки
- Для Railway Hobby плана диска `/tmp` хватает для файлов до ~2 GB

## Команды бота

- `/start` — начало работы
- `/status` — статус очереди
- `/cancel` — отменить свои задачи из очереди
